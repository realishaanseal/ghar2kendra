# Changelog

## 0.5.0

First complete version, ready for Vercel.

- Citizen reporting with Gemini Vision triage, GPS reverse geocoding and in-browser photo compression.
- Live feed and map, ticket pages, login with evaluator profiles, officials' dashboard with SLA clock.
- Civic Memory Engine: asset histories, recurrence and reliability scores.
- Proof-of-Resolution: resident quorum, reviewer gate, automatic recurrence links, advisory photo comparison.
- Civic Missions: clustered reports become coordinated missions with petitions and reminders.
- Neighborhood Impact Radar: followed places, ranked feed, proximity alerts, route hazard check.
- G2K Workspaces: organisation queues, staff assignment, maintenance history and analytics.
- Civic Intelligence Graph: explainable cross-ticket pattern detection with AI explanations.
- Single full-stack app: `/api` server routes replace the separate Express backend; build targets Vercel.
- Up-to-date dependencies with no deprecated packages and no known vulnerabilities (Vite 8, React 19, ESLint 10, Recharts 3, Vitest 5, TypeScript 6); unused UI-kit components removed.
