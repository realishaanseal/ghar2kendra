# Ghar2Kendra (घर से केंद्र तक)

Civic grievance platform that connects citizens, from their doorstep (*ghar*), to the municipal corporations and gram panchayats (*kendra*) responsible for fixing things.

One full-stack TanStack Start app, built for deployment on Vercel.

## Getting started

Requires Node.js 22.13+ (Vercel builds on Node 22).

```bash
cp .env.example .env   # optional: add GEMINI_API_KEY
npm install
npm run dev            # http://localhost:8080
npm test
npm run lint           # ESLint + Prettier for TypeScript files
npm run typecheck
npm run build          # writes .vercel/output
```
